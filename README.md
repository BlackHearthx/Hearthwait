# Hearthwait

See **how long until it is ready** — mead, kiln, smelter, furnace, spinning wheel, windmill, honey, sap, cooking, crops, and plants that grow back.

Look at the piece. The extra line appears under the usual hover text. No combat HUD.

By **blackhearthx**. Follows the game language (English / Portuguese included). Client-side.

## Use

1. Install BepInEx + Jötunn (same as Hearthwife).
2. Put `Hearthwait.dll` and the `Translations` folder in your profile `plugins` folder.
3. Hover a fermenter that is working — you should see **Ready in 32m 10s** (or **Pronto em** in PT).

Toggles live in BepInEx config (`com.blackhearthx.hearthwait.cfg`).
